# Reverse Engineering Sources

The [upstream leanrea repository](../references/leanrea-repo.md) is a Tier C
command cheat sheet and the basis of the installed skill. It is not primary
documentation for underlying system tools.

For each task, treat actual local file metadata, symbols, disassembly and authorized
traces as evidence. Check installed tool help and official documentation when a
platform-specific option is uncertain. The upstream benchmark is too small to predict
results across other tasks or models.
