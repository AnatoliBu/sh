## Agent rules

- Keep provider infrastructure behind an internal adapter.
- Debug from named sessions and evidence before retrying blindly.
- Use interactive viewing for authentication/MFA/ambiguous user-required states.
- Redact or disable observability around credentials and payment secrets.
