# Browser Use

Official source: https://github.com/browser-use/browser-use

Use this authority for agentic browser operation where an LLM perceives browser state, plans, and
acts through local or remote browser sessions.

## Agent rules

- Use agentic browsing for changing/open-ended UI, not as the default for known workflows.
- Bound goals, allowed actions, terminal states, and budgets.
- Keep irreversible payment/account actions behind explicit gates.
- Compile repeated successful paths into deterministic adapters.
