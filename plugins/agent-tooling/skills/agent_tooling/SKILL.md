# Agent Tooling

Инструмент для агента — это интерфейс, который проверяется замером, а не вкусом автора.
Домен покрывает три стадии: спроектировать поверхность, привести CLI к агентскому контракту,
доказать слепым A/B, что стало лучше.

```text
capability contract -> interface design -> retrofit/build -> delivery surface
                    -> blind measurement on a WEAK model -> keep / fix / revert
```

Источник методологии — домен `agent-tooling` Agent KB (`AnatoliBu/sh`). Файлы в
`references/` сгенерированы из него; правки вносятся в домен, не в копию.

## Развилки

```text
новый интерфейс над API/спекой      -> contract-first, генерация CLI+MCP над одним адаптером
человеческий CLI, нужен агентам     -> ретрофит по контракту, минимальный diff
агент игнорирует/ломает тул         -> сначала проверить, доходит ли поверхность до модели
каталог не влезает в список тулов   -> курация / retrieval / workflow tools / code mode
деструктивная операция              -> risk class + одна политика подтверждения + dry-run
```

## Порядок, который экономит раунды

1. Назвать, **что агент сделал не так** (выбрал не тот тул / бросил после ответа / вывалил
   дамп в контекст / ушёл в curl).
2. Определить слой: **discovery** (не знал, что тул есть) / **contract** (не смог
   воспользоваться ответом) / **capability** (нужного ответа нет).
3. Discovery — самый дешёвый и самый частый: строка `description` двигает метрику сильнее,
   чем переписывание тула. Но сначала — доказать, что текст доходит до модели.
4. Заморозить 5–8 слепых задач и ground truth **до** изменения.
5. Две руки, отличающиеся ровно одним, слабая модель, ≥2 раунда.
6. Читать транскрипты, а не только таблицу метрик.
7. Вердикт с числами и границами: одна модель, один уровень усилий, эти задачи.

## Готово ≠ «флаг добавлен»

Капабилити, её risk class и политика подтверждения объявлены; данные на stdout, диагностика
на stderr, `jq`-конвейер живёт; exit-коды различают retry и bail; идентификаторы не
обрезаны; описание говорит, когда брать инструмент; поверхность доходит до модели; слепой
замер на слабой модели показал улучшение — иначе изменение откатывается.
