# Video Color

Цветовой конвейер как инженерная задача с воспроизводимым планом, а не как набор
подобранных на глаз фильтров. Активация: коррекция и сведение дублей, нормализация
источника, маски, профилирование камеры, технический QC рендера.

Источник методологии — домен `video-color` Agent KB (`AnatoliBu/sh`). Файлы в
`references/` сгенерированы из него; правки вносятся в домен, не в копию.

## Стадии — не схлопывать в один фильтр

```text
source -> probe + trust -> input transform -> shots -> технич. коррекция -> shot match
       -> маски (если надо) -> creative look -> output transform + encode -> QC
```

Технический слой и creative look персистятся раздельно. Один непрозрачный LUT «на всё» —
потеря провенанса: через неделю нельзя ни повторить, ни объяснить.

## Развилки

```text
известный Rec.709 + простая коррекция     -> только ffmpeg
log / wide gamut / несколько камер        -> input transform (OCIO/ACES) + коррекция
HDR-источник (PQ/HLG), SDR-доставка       -> сначала решить дальность, потом tone map
телефон на авто-экспозиции                -> бить длинный дубль и править дрейф
неизвестное состояние источника           -> не додумывать: пометить UNKNOWN, разбираться
конфликт «объект vs фон»                  -> маска + вторичная коррекция
характеризация камеры                     -> контролируемая съёмка чарта, не «фикс дубля»
```

## Сначала проверить стек, потом планировать на него

```bash
ffprobe -version | head -1
ffmpeg -filters | grep -E ' (colorspace|zscale|tonemap|maskedmerge|curves|lut3d) '
command -v ociocheck ocioconvert ociobakelut || echo 'OCIO CLI отсутствует'
python -c "import numpy, cv2; print('numpy/cv2 ok')"
```

OCIO и `zscale` есть далеко не на каждой машине. Отсутствующий бинарь — это либо установка,
либо перепланирование на то, что есть, но никогда не описание managed-пайплайна, который
не выполнялся.

## Порядок, который нельзя переставлять

1. **Кадры глазами** по обе стороны каждой склейки и с шагом по длине.
2. **Гипотеза словами**: что именно разъехалось и почему.
3. Опорные объекты сцены (нейтраль, кожа, известный цвет, тень) — по ним и мерить.
4. Кандидаты, включая **no-op**, через одинаковый энкод; обкатать на нескольких кадрах.
5. Показать варианты картинками **до** применения ко всему видео.
6. Персистить победителя в план; финальный рендер решение не пересматривает.

Метрики отвечают на заданный вопрос и не умеют сообщить, что вопрос был не тот. Попиксельное
сравнение двух дублей врёт всегда: между дублями переставляют предметы.

## Готово ≠ exit code 0

Работа закрыта, когда: план воспроизводит рендер; вход/выход цветово объявлены; клиппинг не
вырос без умысла; склейки просмотрены; маски проверены по краям и во времени; `ffprobe`
подтверждает теги/range/pix_fmt доставки; кадры и scopes просмотрены глазами.
